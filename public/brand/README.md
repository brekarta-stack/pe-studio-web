# PE STUDIO Cheer Papertoy Logo

## 콘셉트

소품 없이 두 팔을 크게 들어 올린 사람 인형입니다. 얼굴을 그리지 않고도 V자 팔과 열린 자세만으로 완성의 기쁨, 자신감, 친근함이 전달되도록 만들었습니다. 단순한 다각형 면은 종이를 재단하고 접어 구조를 만드는 PE STUDIO의 작업 방식을 나타냅니다.

## 파일 안내

- `pe-studio-cheer-mark-transparent.png` — 배경 없는 만세 인형 마크
- `pe-studio-cheer-lockup-transparent.png` — 밝은 배경용 세로형 로고
- `pe-studio-cheer-lockup-reversed.png` — 어두운 배경용 세로형 로고
- `pe-studio-cheer-horizontal-transparent.png` — 웹사이트 헤더용 가로형 로고
- `pe-studio-cheer-icon-512.png` — 프로필·앱 아이콘
- `pe-studio-cheer-icon.ico` — 웹 파비콘
- `pe-studio-cheer-logo-preview.png` — 콘셉트 프리뷰

## 권장 사용

- 홈페이지 헤더: 가로형 로고
- 제안서·명함·패키지: 세로형 로고
- SNS·파비콘: 인형 마크 아이콘
- 작은 크기에서는 `PAPER ENGINEERING` 문구를 생략합니다.
