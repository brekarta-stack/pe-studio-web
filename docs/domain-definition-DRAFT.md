## 확인이 필요한 판단 3가지 (이것만 답해도 절반이 풀린다)

1. **biz-b(지역재생)는 "견적"이 아니라 "제안서" 사업 아닌가?** 공모 기반이면 파이프라인 3번째 단계가
   견적서→제안서로 바뀐다. → ⬜ 견적 / ⬜ 제안서 / ⬜ 둘 다
2. **3사업 우선순위**: biz-a가 P1인 건 명확하다. b와 c의 순서는? → ⬜ b→c / ⬜ c→b / ⬜ 동급
3. **분기 목표 숫자**: 위 표의 `⬜사용자` 중 목표·KPI만이라도 정해지면 파이프라인이 "몇 건 모을지"를 안다.
   *모르면 제안값 그대로 두고 2주 뒤 실측으로 교정해도 된다.*
