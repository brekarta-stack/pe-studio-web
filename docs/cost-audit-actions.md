# 비용감사 조치 목록 (2026-07-28) — 진단 완료, 실행 대기

> 감사 결과: **돈은 예산캡을 건 게이트웨이가 아니라, 게이트웨이 밖 미니 잡 하나에서 나가고 있었다.**
> 게이트웨이 안 총 $0.0366(83%가 로컬 흡수, 과금분은 n8n-ops 예산의 0.13%) vs `proactive-nudge` 월 ~$25(**112배**).
> ⚠️ **아직 아무것도 조치되지 않았다 — proactive-nudge는 지금도 28콜/일 돌고 있다.**
> 실행은 **맥 로컬 세션**(기기 접근 가능)이 한다. 이 문서는 근거와 순서.

## 🔴 즉시 (오늘 안)

### 1. `proactive-nudge` OFF — 지출의 99%
- **근거**: 콜당 $0.0275 × 28콜/일 → **월 ~$25**. 출력 2,890토큰 중 **2,708이 reasoning**(89% 낭비), 쓸모 있는 JSON은 182토큰.
  발송 실적 **하루 평균 1건** → 알림 1건 원가 **약 $0.8**.
- **"대체 검증 전 삭제 금지" 예외인 이유**: 대체할 가치 자체가 없다(가치 대비 비용 명백히 역전, 신 시스템에 대응 기능 없음).
- **조치**: `launchctl bootout` + plist를 `.disabled-<날짜>`로. 삭제는 2주 관찰 후.
- **부활 원한다면**: 로컬 티어(`summarize`)로 재구현 → 원가 $0. 프록시 경유 필수.

### 2. 아침 브리핑 active 상태 — **내일 08:30 전에**
- 문서엔 "8종 전부 inactive"인데 **active=t로 오늘 실제 실행됨**. placeholder 상태로 계속 발송된다.
- **조치**: placeholder면 **inactive로 되돌리거나**, 실물(Calendar·Slack) 연결 완료 중 택1. 방치 금지.

### 3. `sns-daily` 정지 — 18일째 산출 0
- 원인: `--print`가 아니라 **워크스페이스 미신뢰 → permissions.allow 82개 통째 무시**. CLI가 파일 안 쓰고 "OK" 출력.
- **조치**: 정지(신 시스템 blog/sns 플로우가 대체 예정). 같은 함정의 피해자가 더 있는지 **2단계 간접참조까지** 재감사.

### 4. `voicebridge` 이중 가동 해소
- 미니·Studio 동시 실행 중. **Studio엔 마이크가 없으므로 Studio 쪽 정지**, 미니 유지.
- 커트오버는 USB 마이크 도착 후 `deploy/studio/voicebridge-cutover.md`대로.

## 🟡 곧

### 5. 나머지 미니 LLM 잡 6종 비용 실측
LLM 부르는 활성 잡 7종 중 `proactive-nudge` 하나만 실측됐다. **나머지 6종(카운슬 3·자기점검 등)이 프록시를 우회하는지, 얼마 쓰는지 미확인.**
→ 같은 방법(실제 1콜 + reasoning 비율 확인)으로 감사.

### 6. `~/.ssh/config`에 ProxyJump
Studio→NAS 직접 SSH 실패(en0/en1 동일 서브넷 이중 연결 추정). 이번 감사도 `ssh -J mini nas`로 우회했다.
→ `ProxyJump mini` 등록. **단 미니 은퇴 후엔 이 경로가 사라지므로**, 근본 원인(이중 연결) 해소도 병행할 것.
